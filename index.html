🐱 О проекте CodeVPN

Персональный и независимый хаб для обхода любых преград. Никаких платных подписок — только чистый софт с GitHub и максимальная скорость.

  • Выбери софт: Скачай проверенный клиент во вкладке «Софт».
  • Забери ключи: Во вкладке «Серверы» пройди загадку и скопируй подписку.
  • Читай сводки: Все апдейты и новости в разделе «Обновления». 🚀

    • 🛡️ Безопасность

    Никакого перехвата трафика. Честный открытый софт с GitHub без слива данных сторонним лицам.

    🚀 Надежность

    Сервера не умирают — один упал, подняли новый! Платные сервисы нервно курят в сторонке.
